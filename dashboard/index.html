❓ What does everything on this dashboard mean?

Top summary cards

Trust — the hardware-attestation level the Darkbloom coordinator has assigned this Mac. hardware means it's eligible to actually receive inference traffic; self_signed means it's online but not yet trusted enough to be routed any jobs. A drop from hardware-level triggers a macOS notification and a red banner automatically.

Daemon — whether the `darkbloom` background process itself is running.

Requests — requests served and tokens processed since the daemon last (re)started. This resets on every restart, so it's not a lifetime total.

Warm models — how many models are currently loaded in memory (instant response) vs. how many are downloaded to disk in total.

Accumulated electricity cost and Net — see the calculation explainer under the cost/revenue chart further down for the exact formula.

Live Power gauges

CPU / GPU / Total — instantaneous power draw read straight from `powermetrics`, sampled ~5 times per second. "Total" adds a fixed 7W estimate on top for everything `powermetrics` can't see (RAM, disk, fans, PSU losses) — real wall power is somewhat higher than shown.

RAM used — system-wide memory pressure, not just this app's usage. Turns red/orange as it approaches full, since that's the exact condition that caused real model-load failures during testing.

Utilization (last hour) — % of the last ~60 minutes (in 5-minute slices) that actually saw new requests arrive, based on the real request counter. A low or 0% reading with a healthy Trust/Daemon status just means genuinely no traffic right now, not a fault — the fan being quiet is expected in that case.

Darkbloom Account ("DB cut")

Real jobs/tokens/payout per model, pulled from your actual Darkbloom account ledger via the sync bookmarklet (not a live connection — you refresh it manually). "DB cut" compares what this dashboard's own naive flat-rate guess would have paid for the same tokens against what Darkbloom's ledger actually paid — it is not an official platform fee, just the gap between a rough local guess and reality, whatever is driving it.

Warmup

Periodically sends a tiny request to the provider's local endpoint to keep the active model loaded in memory, so it's ready instantly instead of needing to reload when the first real request of the day arrives.

Disk Usage

Every model `darkbloom` has downloaded, with size and whether it's the one currently active. Models not currently in use get a one-click "copy remove command" — this dashboard never deletes files itself, it only prepares the exact command for you to run.

Charts

Power history — the same wattage as the live gauges, logged every 5 minutes so you can see trends over hours/days.

Electricity cost vs. estimated revenue — running totals over time; see its own "How is this calculated?" details below the chart for the exact formula.

Ollama indicator

Flags when Ollama has a model loaded in memory at the same time, since that competed for RAM with the Darkbloom provider and caused real crashes during testing on this 48GB Mac.

Still stuck? More detail

A "bookmarklet" is a bookmark whose address is a bit of code instead of a link - clicking it runs that code on whatever page you're currently on. That's why it only works from console.darkbloom.dev: it needs to fetch data from that page.

Dragging works differently per browser: on Chrome/Safari, click-and-hold on the button then move your mouse up to the bar before releasing. If dragging genuinely won't work for you, right-click the bookmarks bar → Add page..., name it anything, and paste the button's link as the URL (right-click the button above → Copy Link).

Electricity cost Estimated revenue
How is the kWh price and Net figure calculated?

Electricity price: fetched live from elprisetjustnu.se (Sweden, zone SE3), re-checked every 15 minutes. It's the actual spot price for the current hour, not an estimate.

Cost so far: every 5 minutes, measured power draw (CPU+GPU from powermetrics, plus a fixed 7W baseline guess for RAM/disk/fans/PSU loss that powermetrics doesn't see) is converted to the energy used in that 5-minute slice, then priced at the current SEK/kWh. Those slices add up into the running "Accumulated electricity cost" card and the cost line on this chart.

Estimated revenue: Darkbloom's alpha pricing is roughly $0.05/M input tokens + $0.20/M output tokens; since darkbloom status only reports a combined token count (not split input/output), this uses a blended midpoint of $0.125/M tokens as a rough stand-in, converted to SEK at the current USD/SEK rate (checked hourly).

Net (estimated) = Estimated revenue − Accumulated electricity cost. This is our own guess built from local numbers, not what Darkbloom actually paid - once the account is synced (see the Darkbloom Account panel above), "Net (real balance)" replaces it with your real ledger balance instead.
